# LeetCode Metric 📊

LeetCode Metric is a web-based profile analytics application that allows users to track and visualize their LeetCode problem-solving progress by simply entering their username.

## 🚀 Features

- Search LeetCode profiles using a username.
- Display total problems solved.
- View Easy, Medium, and Hard problem statistics.
- Display total questions available in each difficulty.
- Calculate and visualize problem-solving progress.
- Display acceptance rate and global ranking.
- Interactive progress circles for better visualization.
- Dynamic data retrieval using an external API.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, layout, and progress circles.
- **JavaScript** – DOM manipulation, event handling, and API integration.
- **Fetch API** – Retrieving LeetCode statistics.
- **REST API** – Fetching user profile analytics.

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Bushra2212/LeetCode-Metric.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser or run it using the VS Code Live Server extension.

4. Enter a valid LeetCode username and click the search button to view the statistics.
